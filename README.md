# FR-Quotify macOS 更新檔

這個公開倉庫存放 **FR-自動化報價單系統**（方睿室內裝修 macOS 報價工具）的簽署安裝檔與 Sparkle 更新來源（appcast），不含原始碼。

- Sparkle 更新來源：<https://raw.githubusercontent.com/EVSDELAT/FR-Automated-Updates_Center/main/appcast.xml>
- 安裝檔與簽署更新壓縮檔：[Releases](https://github.com/EVSDELAT/FR-Automated-Updates_Center/releases)
- 支援平台：Apple silicon Mac，macOS 13 以上

2.0.12 以前的版本沒有內建 Sparkle 更新器：請先手動安裝 2.0.14，之後用 App 內的「檢查更新」安裝 2.0.15 及後續版本。

所有發行檔案皆以 FR-Quotify macOS 程式碼簽署身分與 Sparkle EdDSA 金鑰簽署。本倉庫不存放私密簽署金鑰、原始碼、客戶資料與授權機密。
